# Resora

[English](README.md) | Русский

Клиентский Fabric-мод для сохранения серверных ресурспаков через компактное меню в игре. Поддерживаются Minecraft 1.21.4, 1.21.8, 1.21.11, 26.2 и 26.3.

## Использование

1. Зайди на сервер и прими его ресурспак.
2. Нажми `I`.
3. Выбери **Сохранить текущий ресурспак**.

В меню также можно включить автоматическое сохранение, замену существующего архива и нормализацию ZIP. Настройки хранятся в `config/resora.json`.

Архивы сохраняются в `resora-packs/<host>_<port>.zip` внутри папки игры.

## Сборка

```bash
./gradlew buildAllVersions
```

Готовые JAR для пяти версий появятся в `build/versions/`.
